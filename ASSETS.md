# Bundled assets

The bundled assets include Ceres originals, four wallpapers copied from the
local Ceres background collection, and two user-provided images. The latter
six have unverified provenance and are not covered by this repository's MIT
license.

| File | Origin | License |
| --- | --- | --- |
| `backgrounds/ceres-orbit.png` | Original image generated for Ceres with OpenAI ImageGen on 2026-09-06 | MIT, as part of this repository |
| `backgrounds/black-windows.png` | Local Ceres background collection; origin unverified | License unverified |
| `backgrounds/magenta-skyline.png` | User-provided skyline image, edited and upscaled for Ceres | License unverified |
| `backgrounds/neon-city.jpg` | Local Ceres background collection; origin unverified | License unverified |
| `backgrounds/neon-station.png` | Local Ceres background collection; origin unverified | License unverified |
| `backgrounds/purple-windows.jpg` | Local Ceres background collection; origin unverified | License unverified |
| `backgrounds/ring-gate.jpg` | User-provided image from `Pictures/Saved`; origin unverified | License unverified |
| `unlock.png` | Original geometric artwork generated and refined for Ceres with OpenAI ImageGen on 2026-09-06 | MIT, as part of this repository |
| `preview-unlock.png` | Rendered locally by Omarchy from `unlock.png` | MIT, as part of this repository |
| `preview.png` | Sanitized local screenshot of the installed Ceres theme | MIT, as part of this repository |

Additional personal wallpaper files in
`~/.config/omarchy/backgrounds/ceres/` remain local to that user.
